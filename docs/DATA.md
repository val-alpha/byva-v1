# Data Admission Policy and Verified Sources

Status: Phase 2 review, retrieved 2026-11-26 (initial three sources) and
2026-11-27 (bilingual id+en expansion). Language focus is recorded in D-0016:
BYVA is a bilingual Indonesian + English model; no other language is admitted
for pretraining.

## Language focus (D-0016)

- **Indonesian (`id`)** and **English (`en`)** are the only admitted languages.
- Indonesian sources carry the model's identity purpose; English sources are
  admitted because frontier reasoning/knowledge data is English-heavy and a
  small bilingual model transfers capability across the two languages.
- Every source is admitted per-language-config (e.g. c4 `id`, wikipedia
  `20231101.id` / `20231101.en`); multilingual dumps are only used through
  their per-language subsets.
- Mixture targets are decided per training run and recorded in the run's
  manifest; the default smoke mixture keeps id and en roughly balanced by
  document count.

## Admission rules

A dataset is admitted to the BYVA pretraining corpus only if all of the following hold:

1. **License verified at the source.** The license is read from the dataset's own
   metadata (primary source: Hugging Face dataset API `datasets` endpoint), not from
   third-party summaries. The retrieval records the dataset sha at retrieval time so
   later re-reviews can detect metadata drift.
2. **Redistribution terms understood.** Share-alike or attribution obligations are
   recorded here before any shard is built. Shards derived from a dataset inherit the
   dataset's obligations through the manifest provenance chain.
3. **Provenance recorded per shard.** Every shard manifest carries `sources[{name,
   sha256}]`, normalization, sort key, filter config, and stats (see D-0012). A shard
   without a manifest is not admissible for training.
4. **Corpora stay out of Git.** Raw and processed corpora are excluded per D-0007;
   only manifests, scripts, and small deterministic fixtures are tracked.

## Non-admitted / unreviewed sources

- Anything whose license could not be read from the dataset's own metadata is
  **not admitted** until reviewed.
- The repository license itself remains undecided (D-0009); dataset admission is
  independent of that and still mandatory.

## Pipeline

`training/byva_data.py` + `training/build_shards.py` turn JSONL `{"text": ...}` input
into deterministic, reproducible shards. See `training/README.md` for usage and
`docs/PHASE2_REPORT.md` for the gate evidence.
